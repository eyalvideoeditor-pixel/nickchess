# מאמן השחמט שלי

אתר מקומי שמנתח את 25 המשחקים האחרונים שלך ב-chess.com, מוצא מה הכי מפריע לך, ובונה אימון אישי.

## הפעלה

לחיצה כפולה על `start.bat`, או:

```
python server.py
```

הדפדפן ייפתח על http://localhost:8765. צריך חיבור לאינטרנט (chess.com ו-Lichess).

## מה יש בפנים

- **ניתוח** — Stockfish 18 (NNUE) רץ בדפדפן על כמה ליבות במקביל. כל מהלך מסווג
  (בלנדר / טעות / אי-דיוק) ולפי סיבה: כלי תלוי, טקטיקה של היריב, איום מט, פספוס טקטיקה,
  פספוס מט, טעות עמדה. בנוסף: שלב המשחק, לחץ זמן (לפי השעון ב-PGN), ומימוש יתרון.
- **הדוח שלי** — לאן הלך היתרון שלך, ומה הכי כדאי לתקן קודם.
- **המשחקים** — מעבר מהלך-מהלך עם גרף הערכה; כל מהלך לא טוב אפשר "לתקן" באימון.
- **מנתח משחקים** — קישור ל-chess.com / Lichess, PGN, או משחק מהרשימה. כל מהלך של שני השחקנים
  מקבל ציון בשיטת chess.com (Stockfish עומק 16, שתי האפשרויות הכי טובות בכל עמדה) והסבר:
  שבותה (מבריק) · ניק (Great) · זה הכי טוב · זה מגניב · לא רע · למדת חבוב (ספר) ·
  לא ככה (אי-דיוק) · אידיוט (שגיאה) · יא עיוור (Miss) · אוטיסט (בלנדר).
  השמות מוגדרים ב-`REVIEW` שב-`js/content.js`.
- **אימון** — תרגילים מהעמדות שלך:
  - *תקן את הטעויות שלך* — מצא מהלך טוב יותר (המנוע בודק כל ניסיון).
  - *הפוך את הלוח* — שחק בתור היריב והענש את הבלנדר שלך.
  - *בטוח או בלנדר?* — אימון ישיר של בדיקת בלנדר.
  - חידות לפי נושא + *מצב בדיקת בלנדר* שמחייב לאשר כל מהלך.
- **חידות מובחרות** — 6,150 החידות הכי מדורגות ממאגר Lichess (42 קטגוריות), ואחריהן
  חידות חדשות ללא הגבלה מה-API של Lichess.
- **פתיחות** — מערך לונדון, הפתיחה האנגלית, המשחק האיטלקי והקארו-קאן (14 קווים). מצב "למד"
  עם הסבר לכל מהלך, ומצב "תרגל" מהזיכרון עם חזרה מרווחת (כל קו חוזר כשהגיע זמנו).
- **ניק** — הכלב-מאמן. מופיע בכל מקום שיש טקסט (ניתוח, אימונים, חידות, פתיחות) ומקריא בקול
  (קול עברי של Windows/Edge; כפתור 🔊 למעלה משתיק).
- **צ'אט עם ניק** — מאמן AI שמכיר את הניתוח שלך. בחינם עם מפתח של Google Gemini
  (aistudio.google.com/apikey), או בתשלום עם Claude (`claude-opus-5-5`). מדביקים את המפתח פעם אחת
  בעמוד הצ'אט — האתר מזהה לבד של מי הוא (נשמר רק ב-`.secrets.json` המקומי).

ההתקדמות (דירוג חידות, חידות שנכשלת בהן, ניתוחים שמורים) נשמרת בדפדפן.

## קבצים

| | |
|---|---|
| `js/analysis.js` | סיווג מהלכים, זיהוי סוג הטעות, פרופיל החולשות |
| `js/content.js` | כל הטקסטים בעברית ותוכניות האימון |
| `js/trainer.js` | מסך האימון (חידות ותרגילים) |
| `js/review.js` | מנתח המשחקים: ציון לכל מהלך, הסברים, סיכום |
| `js/nick.js` | הדמות של ניק: בועת דיבור + הקראה בעברית |
| `js/openings-data.js` | הקווים של הפתיחות וההסברים לכל מהלך |
| `js/chat.js` + `server.py` | הצ'אט עם ניק (Claude דרך ספריית anthropic) |
| `data/top-puzzles.js` | החידות המובחרות — נבנה ע"י `tools/build_puzzles.py` |
| `data/openings.js` | עמדות ספר הפתיחות — נבנה ע"י `tools/build_openings.py` |
| `engine/` | Stockfish 18 lite (WASM) |
| `vendor/` | chessground (הלוח של Lichess) ו-chess.js |
